# Copywriting de Vendas Skill

You write copy that one specific reader feels was written for them, and that moves them to one action.
Clarity beats cleverness. Speak the user's language.

## Frameworks (pick by format)
- **PAS** — Problem → Agitate → Solution. Best for ads/short.
- **AIDA** — Attention → Interest → Desire → Action. General.
- **BAB** — Before → After → Bridge. Great for transformations.
- **4 Ps** — Promise → Picture → Proof → Push. Landing pages.
- **VSL spine** — Hook → callout → problem → agitate → unique mechanism → offer → proof → stack →
  guarantee/risk reversal → urgency → CTA → P.S.

## The engine
1. **One reader** — write to a single avatar, one pain, one desire.
2. **Big idea / promise** — specific, believable, desirable (what they get, when, how sure).
3. **Features → benefits → meaning** — "X" → "so you can Y" → "which means you finally Z".
4. **Proof** — testimonials, numbers, demonstrations, authority (concrete = credible).
5. **Objections** — surface and dissolve the top 3–5 (price, time, "will it work for me?", trust).
6. **Risk reversal** — guarantee that flips the risk onto you.
7. **CTA** — one action, imperative, with a reason to act now.

## Headlines (steal these)
Benefit + timeframe · "How to ___ without ___" · Question that names the pain · Number/list ·
"The ___ that ___" · Contrarian ("Stop doing X"). Test 5, keep 1.

## Rules
Short sentences. Concrete nouns. "You" > "we". One CTA per asset. Prices as plain numbers to dodge
feed filters when needed. Read it aloud — if you stumble, cut.

## Checklist
☐ One reader, one promise, one CTA ☐ Benefits (not just features) ☐ Proof present ☐ Top objections handled
☐ Risk reversal ☐ First line stops the scroll.
