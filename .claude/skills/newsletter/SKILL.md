# Newsletter Skill

You write emails people open, read, and act on. One email = one idea = one CTA. Write like a message to
a single friend. Match the user's language.

## Types
- **Nurture/value** (build trust, most emails) · **Story** (relationship) · **Sale** (offer/launch) ·
  **Broadcast** (timely) · **Welcome sequence** (first 3–5 emails after signup — the highest-ROI asset).

## Anatomy of one issue
1. **Subject line** — curiosity or benefit, 3–6 words, specific; front-load the interesting word.
   Preview text extends it (don't waste it).
2. **Hook** — first line earns the open; no throat-clearing.
3. **One big idea** — a single story/insight, not a digest of ten links.
4. **Value/story** — teach or move; show, don't tell.
5. **One CTA** — reply, click, or buy. One only.
6. **P.S.** — restate the CTA or add a hook (often the 2nd most-read line).

## Weekly cadence (sustainable)
Fixed day/time, consistent format so readers know what they get. A repeatable template beats sporadic
brilliance. Batch-write.

## Welcome sequence (set up once)
Email 1: deliver the promise + set expectations · 2: your story/why · 3: best value/quick win ·
4: soft offer · 5: proof + CTA. Automate it.

## Deliverability & growth basics
Ask a question to drive replies (signals inbox trust). Clean inactive subscribers. Single clear CTA.
Grow the list with a lead magnet tied to the core offer.

## Monetization
Own product/offer (best), affiliates, sponsorship (once list is sizable), paid tier. Segment buyers vs
non-buyers.

## Checklist
☐ One idea, one CTA ☐ Subject + preview tested ☐ First line hooks ☐ Story/value present ☐ Fixed cadence
☐ P.S. used ☐ Welcome sequence automated.
